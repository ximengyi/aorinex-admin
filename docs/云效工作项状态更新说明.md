# 云效工作项状态更新说明

前端开发任务完成后，需要在云效上把对应工作项状态改为「已完成」。

## 所需信息

调用云效 MCP 接口需要：

| 参数 | 说明 | 获取方式 |
|------|------|----------|
| **organizationId** | 组织 ID | 云效 → 组织设置 → 基本信息 |
| **spaceId** | 项目 ID（aorinex 项目） | 进入 aorinex 项目 → 项目设置或 URL 中 |
| **workItemId** | 工作项 ID | 工作项详情页或列表接口返回 |

## 操作步骤

1. 在 Cursor 中提供上述 **organizationId** 和 **spaceId**，可让 AI 代为：
   - 搜索 aorinex 项目下的前端相关任务（`search_workitems`）
   - 将对应工作项状态更新为「已完成」（`update_work_item`，status 使用项目内「已完成」对应的状态 ID）

2. 若已知具体工作项 ID，可直接提供 **organizationId** 和 **workItemId**，由 AI 调用 `update_work_item` 更新状态。

## 状态 ID 参考

云效常见状态 ID（以实际项目工作流为准）：

- 开发完成：100011（Development Complete）
- 测试中：100012（In Testing）

「已完成」的具体 ID 需在项目工作流配置中查看，或通过 `get_work_item` 接口返回的状态列表确认。
